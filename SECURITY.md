# Security policy

Please do not report a security problem in a public issue.

Use GitHub's private vulnerability reporting for this repository (the **Security** tab, **Report a vulnerability**).
If that button is not shown, open a public issue that says only that you have a security report and asks for a
private channel - with no details.

What to include: what you found, how to reproduce it, and what it could let someone do. You will get an answer within
five working days. A confirmed problem is fixed with a test that fails without the fix, and recorded in
`docs/FAILURE-MODES.md` once the fix is live.
