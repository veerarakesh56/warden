# G10 integration held-out benchmark: independent review

Reviewed 2026-10-10 by an independent Claude agent (Claude Code, Opus 5.5). All 42 `incidents/*.json`, `key.json` and
`README.md` were read line by line. The only WARDEN code read was `aws_stack.py`, `aws_describe.py`, `resources.py`,
`aws_backend.py`, `tools.py`, `evidence.py`, `quarantine.py` and `models.py`. No case file was changed and no AWS call
was made. A scratch script imported `warden.evidence.index` and `_kind`, which showed how each line is trusted and
rendered for the model.

The mechanical checks passed: every label set matches `labels_for`, reader order, CHANGE-name order, CHANGE windows,
LOG windows, metric key names, `_dims` sorting, STATE field naming (including `Provisioned_BrokerNodeGroupInfo_InstanceType`
and `LoadBalancerArns=1`), and the tool-error chains. The problems below are about what is in the evidence, its realism,
and the answer keys.

Severity: HIGH means the case is wrong or unanswerable as keyed, or the evidence is materially unlike what WARDEN would
gather. MED means a real defect that weakens the case. LOW is a nit.

## Findings about WARDEN (not case defects)

- A CloudWatch `PartialData` partial (`alarm metrics: <key> PartialData (the series may be incomplete)`) has no
  `[outcome]` tag, so `tool_error_text` renders it `logs alarm metrics: failed (unclassified)`.
- The CloudTrail truncation partial (`changes: more writes to X than were read`) also renders
  `failed (unclassified)`, so the model cannot tell "too many changes" from "read failed".
- `ListExecutions` and `StartQuery` are not in `evidence.READ_OPERATIONS`, so those failures render without their
  operation (`logs states-failures: access denied`).
- README's finding is confirmed: all 6 API Gateway STATE lines are demoted (`execute` in `disableExecuteApiEndpoint`).
- Metric-math alarms produce no metrics, and the REST/HTTP API symptom metrics are never read (the `apigw` reader needs
  an `apigw` label that `labels_for` never gives). API Gateway faults behind a metric-math alarm therefore cannot show
  their symptom.
