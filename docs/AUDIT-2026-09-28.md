# Whole-system audit, 2026-09-28

Three read-only audits covered every module, script, IaC file, workflow, doc and test. They were
run after v0.10.0 was wrongly announced as "Phase 2 done". This file lists every finding, the work
group that fixes it (see [`ROADMAP.md`](ROADMAP.md)), and its status.

**The rule** (`tests/test_register.py` enforces it in CI):
- A row is closed only as `DONE-local`, citing a test that exists, or as `DONE-live`, citing the
  window and its evidence.
- `DEFERRED` counts as closed only with `owner-agreed <date>`.
- Any open row whose group is at or before the current group fails CI.

Groups run in order: G0 → G1 → G2 → G3 → G4 → G5 → G6 → G7 → G8.

**Status values:**
- `OPEN`: not fixed yet.
- `DONE-local`: fixed, and the cited test proves it.
- `DONE-live`: proven in an AWS window.
- `DEFERRED`: postponed, with the owner's agreement recorded.
- `WITHHELD`: a finding that is exploitable on the live account today. Its details are published
  only after the live fix (plan rule 10: the repository is public).
